RUN ON ANOTHER WINDOWS x64 LAPTOP
1. Stop ShortsFlow using STOP-SHORTSFLOW.cmd.
2. Copy this ENTIRE shortsflow folder, including models, python, venv,
   ffmpeg, node, workspace and tools.
3. Put it on the other laptop. E:shortsflow is easiest for cached jobs.
4. Double-click RUN-SHORTSFLOW.cmd.
5. Open http://127.0.0.1:7875.
Ollama starts automatically; no separate Ollama installation is needed.
To resume the preserved Small Talk job use RESUME-LAST-VIDEO.cmd.
An interrupted clip may start rendering again from its beginning.
